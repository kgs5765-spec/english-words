# 🦁 영어 단어 놀이터

초등학교 저학년을 위한 영어 단어 문제 앱입니다.

👉 **바로 하기: https://kgs5765-spec.github.io/english-words/**

## 놀이 방법
- 📖 **단어 카드**: 카드를 누르면 영어 발음을 들려줘요
- 🖼️ **그림 보고 고르기**: 그림에 맞는 영어 단어를 골라요
- 👂 **듣고 고르기**: 발음을 듣고 맞는 그림을 골라요
- 💬 **뜻 고르기**: 영어 단어의 우리말 뜻을 골라요
- 🔤 **철자 맞추기**: 글자를 순서대로 눌러 단어를 완성해요

주제: 동물, 과일·음식, 색깔, 숫자, 몸, 물건·자연 (단어 85개)

한 판에 10문제이고, 점수에 따라 별을 받아요. 모은 별과 최고 기록은 브라우저에 저장돼요.
